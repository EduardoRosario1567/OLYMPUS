# OLYMPUS Work v2.5.1 — Offer Engineering e Design Skills

## Resultado

O catálogo proprietário passa a oferecer sete novas capacidades nativas:

- Offer Engineering;
- Emil Design Engineering;
- UI/UX Pro Max;
- Web Design Guidelines;
- Brand Kit;
- Extract Design System;
- Image to Code.

## Modelo de integração

As skills são contratos declarativos carregados pelo registro nativo do OLYMPUS. Cada contrato define gatilhos específicos, ações permitidas, dependências, limites, orientação compacta e critérios verificáveis de conclusão. Isso reduz raciocínio repetido dos modelos e conserva o controle de execução no OLYMPUS.

Offer Engineering foi criada como capacidade proprietária. As outras seis foram reescritas para o contrato do OLYMPUS a partir de conceitos de repositórios MIT, com URL e licença preservadas nos metadados. Nenhuma dependência, script ou código executável externo foi incorporado.

## Proteções

- Offer Engineering proíbe depoimentos, escassez e resultados inventados.
- Brand Kit não promete originalidade ou disponibilidade de marca sem pesquisa própria.
- Extract Design System limita a análise a referências públicas ou autorizadas e não copia ativos protegidos.
- Image to Code exige referências autorizadas e separa fatos visíveis de suposições.
- Todas as skills de interface compõem acessibilidade e testes quando aplicável.

## Verificação

O teste de integração confirma carregamento, ativação, metadados, dependências e roteamento discriminante para as sete capacidades. A liberação exige também regressão completa e a simulação determinística da landing page do investidor.
