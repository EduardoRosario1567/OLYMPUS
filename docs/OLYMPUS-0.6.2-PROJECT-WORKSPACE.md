# OLYMPUS 0.6.2 — Project Workspace

Adds the persistent project boundary above execution jobs.

- Stable project metadata and root directories.
- One isolated execution workspace per execution under `.executions/<execution_id>`.
- Project execution workspaces are retained for resume and audit.
- API routes create, list and retrieve projects.
- Existing cloud execution contracts remain backward compatible.
- Authentication and tenant authorization remain scheduled for 0.6.3.
