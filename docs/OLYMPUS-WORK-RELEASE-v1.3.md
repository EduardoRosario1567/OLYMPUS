# OLYMPUS Work v1.3 — Conversational UX

## Resultado

A experiência principal agora segue um fluxo conversacional e minimalista. O
usuário descreve o resultado em uma única caixa, acompanha a missão como uma
resposta do Olympus e baixa a entrega no mesmo lugar.

## Mudanças

- `/missao` passou a ser a página inicial após a autenticação.
- O antigo dashboard de métricas deixou de interromper o fluxo principal.
- A navegação foi reduzida a Nova missão, Projetos e Histórico.
- Projeto e criação de projeto ficam dentro do compositor.
- Progresso, retomada, cancelamento e download permanecem no diálogo.
- Erros técnicos são convertidos em mensagens claras e não expõem provedor,
  modelo, endpoint ou infraestrutura.
- A identidade Olympus e o símbolo de Zeus foram preservados com menor peso
  visual.

## Compatibilidade

Nenhum contrato de API foi alterado e nenhuma dependência foi adicionada.
