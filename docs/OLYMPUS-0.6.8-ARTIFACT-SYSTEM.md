# OLYMPUS 0.6.8 — Artifact System

Implements the v1.0 Artifact domain foundation: typed artifacts, tenant/project/mission/execution linkage, immutable versions, SHA-256 integrity metadata, controlled storage/download, deletion, and Verification Engine evidence.

Supported types: code, document, spreadsheet, presentation, page, image, data, other.

Security: server-generated storage paths, tenant-scoped lookup, sanitized filenames, storage-root containment.
